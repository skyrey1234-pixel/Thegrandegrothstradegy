# The Grande Growth Strategy App

This repository now includes a runnable web app that packages the full strategy zip into one interface.

## What's included

- Strategy documentation viewer (all markdown docs from the zip)
- Embedded pitch deck viewer
- Section navigation + search

## Run locally

1. Start a local static server from this repository root:
   ```bash
   python3 -m http.server 8080
   ```
2. Open:
   `http://localhost:8080`
